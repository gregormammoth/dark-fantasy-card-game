---
title: Privacy Policy
description: How Hollowfort handles guest play, cloud saves, and analytics during Beta.
---

Hollowfort is an early Beta product. You can play at `/play` without creating an email account.

## Guest identity

Starting a run creates a guest `playerId` so the game can save progress and attach optional feedback. Full login and player profiles are not part of Beta.

## Cloud saves

Run state (deck, exploration, quests, crowns, seed) may be stored on the Hollowfort API so you can resume the same prison escape. Closing the tab does not always end the run.

## Analytics

The client may send product events such as session start, battles, unlocks, and escape. These help answer how far players get — not advertising profiles.

## Feedback

If you submit feedback, the message and optional contact are stored so the team can read it. Do not send secrets or personal data you do not want stored.

## Contact

This page will be updated as online services grow. Until then, treat the Beta as a guest-run demo with cloud persistence.
